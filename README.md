
# 🐾 PawPal - Pet Adoption Platform

## About PawPal
PawPal is an online pet adoption platform designed to connect homeless pets with loving families.

Our goal is to make pet adoption simple, safe and accessible.

## Features

- User Registration
- User Login
- View Available Pets
- Pet Details
- Search and Explore Pets
- Online Adoption Requests
- Firebase Authentication
- Firebase Firestore Database
- Firebase Storage

## Platforms

- Website
- Android Application (planned)

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Firebase Storage

## Installation

1. Clone this repository.
2. Open the project folder.
3. Configure Firebase credentials.
4. Enable Firebase Authentication.
5. Create a Firestore database.
6. Configure Firebase Storage.
7. Run the website using a local development server.

- users
